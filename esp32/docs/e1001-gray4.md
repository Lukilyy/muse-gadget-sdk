# E1001 four-gray display

The E1001 keeps `display.draw_url` as the existing black-and-white path.
For photographs, call `display.draw_gray4_url` with the same `url` and optional
`row`. The URL may point to a baseline JPEG or raw RGB565 image. The device
converts it to black, dark gray, light gray and white, then performs one full
UC8179 gray refresh. JPEG downscaling still uses the existing 1/2, 1/4 and
1/8 decoder steps; the image is horizontally centered and defaults to row 0.
The E1001 panel's measured gray-plane polarity is inverted relative to the
nominal image levels, so the firmware reverses the plane codes before refresh.

```json
{"command":"display.draw_gray4_url","params":{"url":"https://example.com/photo.jpg"}}
```

The successful response includes `gray_levels: 4`. The panel status screen
remains black and white. The gray waveform and dual-plane encoding follow
Seeed_GFX2's UC8179 implementation; the LUT data is in
`main/uc8179_gray4_lut.h` under Seeed_GFX2's MIT license. An E1001 hardware
test with an 800x480 four-level chart confirmed the physical order as black,
dark gray, light gray and white after the plane-code inversion.
